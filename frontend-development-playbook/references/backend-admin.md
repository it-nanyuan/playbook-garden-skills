# Backend Admin

## Layout

- 复杂后台优先分栏布局或多级菜单
- 顶部导航和标签栏固定
- 菜单区和内容区独立滚动
- 表格操作列固定，宽列横向滚动
- 已有后台先复用真实外壳和列表骨架；不要重复外层边距或另起侧栏、标签栏、筛选和分页体系
- 仪表盘在标签栏后直接进入紧凑指标与主内容；管理列表避免常驻解释横幅

## Interaction

- 筛选区清晰、常用条件优先
- 列表页优先效率，不靠大量说明文案
- 详情、编辑、批量操作的层级要明确
- 状态、权限、错误、空态要有统一反馈
- 切换已打开页面时按产品需要保留局部筛选和表格状态，避免无端重置或空白闪烁
- 长弹窗限制视口高度，标题/操作固定，内容区独立滚动

## Visual

- 避免大标题、大段说明和卡片墙
- 重点用布局、层级和组件组织复杂信息
