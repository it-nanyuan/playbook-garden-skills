# Rust Development Playbook

Use this skill for Rust APIs, async services, workers, CLIs, libraries, and system tools.

Before implementation, clarify:

1. Project type and runtime model
2. Framework or library stack
3. Single crate or workspace layout

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
