# Go Development Playbook for Claude

Use this instruction set when implementing Go backend services or internal tools.

## Rules

- Keep package boundaries clean.
- Handle errors explicitly.
- Comment exported APIs and complex logic.
- Preserve context, logging, and testability.

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
