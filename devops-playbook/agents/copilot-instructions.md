# DevOps Playbook for GitHub Copilot

Apply these rules when planning or executing operational work.

## Workflow

- Confirm environment and operational task first.
- Review release window, rollback path, dependencies, and monitoring state.
- Verify service health and logging after execution.

## Safety Standard

- Production changes require rollback planning.
- Configuration must be traceable.
- Monitoring and logs are baseline requirements.

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
