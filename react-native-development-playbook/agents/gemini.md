# React Native Development Playbook

Use this skill for React Native screens, shared business modules, navigation flows, state containers, native bridges, and hybrid mobile app features.

Before implementation, clarify:

1. App architecture type
2. Navigation and state strategy
3. Whether the work belongs to UI, logic, state, service, or bridge layer

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
