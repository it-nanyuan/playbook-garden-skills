# C++ Development Playbook

Apply this playbook when working on C++ libraries, services, SDKs, desktop modules, performance-sensitive components, or system tools.

Start by clarifying:

1. Is the project a library, service, desktop module, or system-level component?
2. Which build system is used?
3. What are the project rules for exceptions, memory ownership, and threading?

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
