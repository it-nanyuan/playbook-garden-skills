# Testing Playbook

Use this skill for test planning, case design, regression, acceptance validation, defect management, and release-risk assessment.

Inspect changed UI interactions and running APIs when feasible; report automated, browser/simulator, real-service, and device/field evidence separately.

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
