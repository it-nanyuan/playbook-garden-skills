# Product Manager Playbook

Use this skill when you need to behave like a product manager and orchestrate multiple domain skills.

Before execution, clarify:

1. Business goal
2. User and scenario
3. Scope and non-goals
4. Which downstream skills should be involved

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
