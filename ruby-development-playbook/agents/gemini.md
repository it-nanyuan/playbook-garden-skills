# Ruby Development Playbook

Use this skill for Ruby applications, Rails systems, APIs, background jobs, and business modules.

Before implementation, clarify:

1. Framework choice
2. Application shape
3. Job and queue strategy

## Cross-Project Standards

新项目启动、设计系统制定或跨页面规范统一时，先读取 `project-standards-playbook/SKILL.md` 及其适用细则；小修复按影响范围应用，保留已有确认参数。
