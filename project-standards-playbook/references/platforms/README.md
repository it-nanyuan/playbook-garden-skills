# 项目统一标准平台入口

`SKILL.md` 为入口，`references/standards.md` 为共同规则，`platform-profiles.md` 为端专项，`project-start-template.md` 为启动模板，`evidence.md` 为来源和边界。平台适配不复制规则全文；读取同一份规范源。

- 结构化入口：`agents/openai.yaml`
- 其他平台入口：`agents/claude.md`、`agents/copilot-instructions.md`、`agents/cursor.mdc`、`agents/gemini.md`

先读取项目记忆；根据任务应用条款，不把模板提升成每次都必须完整执行的流程。已确认项目参数优先于默认值，待审方案不视为用户认可。
