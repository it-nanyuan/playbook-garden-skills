# 端与产品专项规则

使用共同标准前先选产品类型；多端分别定义参数。这里的项目数值是有来源的专项合同，不是新产品全局常量。来源见 [规则依据](evidence.md)。

## 手机与平板 App

- 根 Tab 是同级切换，保留页面状态，不连续 push；详情进入层级栈，返回恢复原状态。iOS 验证返回按钮、交互式侧滑的完成与取消；模态和根页按自身语义处理。
- 固定底部操作、输入区与滚动内容职责清楚，键盘出现与退出后布局恢复。重要操作保持可达，去掉与系统/顶部返回重复的底部返回按钮时保留选择、提交等真实动作。
- 触控命中范围按目标平台和项目合同检查，现有 iOS 项目常以 44×44 作为基线样本；小图标和行内细密视觉不缩减命中区。日历等特殊组合另记例外。
- 平板按任务安排分栏与可用宽度，保留工具和操作密度，不把手机页面整体放大。

## 后台与业务网页

- 已有系统先复用实际 AppShell、导航、折叠、hover 子菜单、筛选和列表骨架。导航/标签固定，菜单与内容滚动所有权清楚。
- 有侧栏的业务表单利用可用内容宽度，按主表单与辅助上下文组织；独立登录可居中。空间不足时辅助区下移或折叠。
- Dashboard 直接进入紧凑 KPI 与业务模块，不叠独立大标题、解释条和重复刷新。表格宽时保留横向滚动及固定操作列；零结果隐藏分页整条，保留有语义空态。
- 运营/MES/物流等企业移动界面可采用已确认的蓝白密度和语义状态色；消费者产品、营销站和不同品牌不强制套此配色。

## 桌面工作台

- 主导航固定，替换工作区；工作标签、项目/环境选择、分栏各有稳定身份。模块切换、关闭前序标签或重排不丢未关闭页面的草稿与资源。
- 菜单、tooltip、选择框、弹窗采用紧凑桌面密度，键盘焦点、方向键、确认/取消、IME 组合输入和焦点恢复分别处理。
- 按可用窗口约束组织工具栏换行、可调分栏和独立滚动；主区、窄侧栏空态分别定图形大小。跨平台分别构建、交互与打包验收。
- 表格、编辑器、终端等专业能力经组件接口接入，UI 选择态与业务执行/提交范围分开，不能让视图复选框承担远端事务状态。

## 公共导航与弹窗的状态

- `shared-design` 是公共设计库；Figma 文件标识见 evidence，实时可用组件与发布状态在使用时读取。组件“已发布”不等于设计方案“用户已认可”。
- Crest 同表面滑动方案已获确认，仍按产品选择，不强制替代所有原生 Tabbar；Split（断轨悬浮）被拒绝，后续 Saddle 改稿截至来源记录尚未获用户认可。
- 公共移动 Dialog 有等宽等高操作、语义色与可编辑内容，listenloop 已按项目主题复用；其342宽、52按钮等是组件版本参数，不用于 DevDeck 桌面。
- 发布公共组件时只包含本次授权的更改，排除历史待发布修改；验证至少一个实际消费实例。项目使用发布版本，不以本地未发布主组件已改推定跨文件传播。

## 专用场景

| 场景 | 复用的共同要求 | 必须另外确定 |
| --- | --- | --- |
| 地图/导航 | 保留操作、真实状态、运行证据 | 地理来源、路线可信度、底图与权限；未现场验证的坐标/路径明确待复核 |
| 音频/语音 | 状态、取消、持久化和错误真实 | 队列、时长、重复/静音、暂停恢复、媒体权限与设备听测；原型跳转不是声音已验证 |
| 硬件圆屏 | 稳定导航、可读性、反馈和实物证据 | 实际屏幕/输入方式/性能；voice-puck的466×466不套手机390×844 |
| 空间设计 | 同一数据源、可编辑几何与交付追溯 | 真实尺寸和比例；bathroom-layout效果图只是视觉参考，实测后深化，不能用渲染图证明尺寸 |
| 支付与权益 | 明确价格来源、操作结果、取消和失败 | 商店/支付真实验真、周期、退款/恢复与正式配置；示例价格和显式Plus预览不代表真实权益 |
